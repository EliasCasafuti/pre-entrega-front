# 👟 EC Sneakers

Sitio web de ecommerce de zapatillas desarrollado con HTML5 y CSS3 puro. Incluye página de inicio con productos destacados, sección de reseñas y formulario de suscripción.

---

## 🚀 Tech Stack

- HTML5
- CSS3 (Flexbox)
- Font Awesome (íconos)
- Google Fonts (Bebas Neue, Roboto Condensed)

---

## 📁 Estructura

```
ec-sneakers/
├── index.html
├── styles.css
├── contacto.html
└── img/
```

---

## ✨ Features

- Navbar fija con íconos y efecto hover
- Hero con imagen de fondo desenfocada y texto centrado
- Cards de productos con imagen, precio y botón de carrito
- Sección de reseñas con foto de autor, estrellas y opinión
- Newsletter con input de email y botón de suscripción
- Footer minimalista con columnas de contacto y links
